# Scenario-level confidence intervals (block bootstrap)

`scenario_bootstrap.py` adds 128-px block-bootstrap 95 % CIs (200 replicates) and Benjamini-Hochberg-corrected paired tests to every corrected-EM validation scenario. The block length is set from the measured integral scale (≥ 2 × 53 px), not chosen for convenience. Point estimates are verified against `validation_emfix.json` to 1e-9 by a sync check that also runs in `validate_pipeline.py`.

## Reading

1. **EM is the load-bearing modality**: EMI failure costs −0.187 recall (CI excludes 0 by a wide margin); EMI degradation costs −0.129; removing both EM layers costs −0.045.
2. **TIR is redundant for the proxy**: TIR degradation *increases* recall (+0.028) — dropping TIR sharpens agreement with the gamma-derived proxy.
3. **EMI+TIR failure is indistinguishable from normal** (Δ −0.0026, BH p 0.91): with both gone, gamma alone carries the proxy — the same circularity the ablation shows (gamma-only F1 0.519).
4. **CORAL significantly hurts** (−0.015): the negative CORAL result is CI-backed, not a point estimate.
5. **Temperature recall rises away from 25 °C** (+0.030 at −60 °C, +0.018 at +80 °C, +0.000 at 25 °C): the noise plus quality-weight response inflates recall while F1 drops (0.490 → 0.417 at −60 °C), i.e. more positives are flagged but less precisely. Report F1 alongside recall.
6. The synthetic domain shift is too weak to matter (direct transfer p 0.67) — the cross-domain scenario needs a stronger construction before any claim.

## Caveats

- 200 replicates × 128-px blocks; block CIs remain narrow because N_eff is small but the design effect is accounted for.
- The paired tests use per-block recall differences; blocks without positives contribute zero.
- Scenarios use the corrected-EM model; legacy point estimates remain in `validation.json` without CIs.
